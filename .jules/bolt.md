## 2024-04-25 - [Optimize Accord Violation Check]
**Learning:** In the core turn resolution logic of `engine.py`, identifying if a faction violated an active Accord (treaty) by attacking another faction was previously done using an O(A * N * P) nested loop that repeatedly fetched Player and Node data from the database. This was highly inefficient. By pre-calculating a `hostilities_map` (attacker ID -> set of victim IDs) during the combat resolution phase (which already iterates through actions), we can perform the Accord violation checks in O(1) time without extra database queries.
**Action:** When working with nested relationships that require checking historical events within the same epoch/loop, prefer constructing lookup maps (e.g. `Dict[int, set[int]]`) during the initial event parsing pass instead of re-calculating or re-querying the data for each relationship pair.
