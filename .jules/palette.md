## 2024-05-24 - Accessibility: ARIA Labels on Icon Buttons\n**Learning:** Icon-only close buttons in dynamic JS-rendered components (like `MissionPanel` and `HelpOverlay`) frequently omit `aria-label`s, breaking screen reader navigation. It is essential to proactively check template literals for accessible interactive elements.\n**Action:** When adding new UI components using JS template literals, ensure all `button` elements containing only icons or special characters (like `\u2715` or `×`) explicitly declare an `aria-label` attribute.
